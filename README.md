# PersonalWiki

A static Wikipedia-inspired personal profile page for recruiters.

## Edit

- Open `index.html` to refine the CV-derived profile text.
- Replace the current portrait image in `assets/` and update the infobox `src` in `index.html` if you want to change it later.
- Update the GitHub, LinkedIn, email, and portfolio links.

## Host

This project is plain static HTML, CSS, and JavaScript. It can be hosted directly on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static web server. No build step is required.

For a local preview, open `index.html` in a browser.
